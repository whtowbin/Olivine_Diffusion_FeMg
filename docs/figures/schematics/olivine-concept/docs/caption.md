# Caption

**Figure 1 | The width of a relaxed growth step, read with the diffusivity for its direction, is a clock.**
Fe-Mg interdiffusion smooths a step in forsterite content (Fo) that growth left in an olivine crystal. The profile's width grows as √(D t), so a measured profile fixes the product D × t. D along c [001] is about six times D along a [100] or b [010] (the anisotropy in the Fe-Mg diffusivity laws FORSTER uses), so the time follows only once the profile's direction in the crystal is known.
**a**, Polished section through a zoned olivine crystal in contact with melt, with a lower-Fo rim zone around a higher-Fo core (normal zoning is drawn; reverse zoning is treated the same way). Electron microprobe spot analyses run from the rim (the crystal edge, held at the rim-zone Fo during diffusion) inward, along a [100] (blue) and along c [001] (orange). The section contains a and c; b points into the page. The crystal outline is generic, not a specific habit, and the number and spacing of spots are schematic. Each traverse is drawn to the distance scale of its plot in b.
**b**, Fo against distance from the rim along each traverse: the starting step (t0, dashed) and three later times (light to dark), the same three times in both plots. Along c the profiles are √6 ≈ 2.4 times wider at every time, because D is six times larger. Brackets span the 16-84 % rise of the latest profile. The step sits at the same distance from the rim in both plots to isolate the effect of D. In real crystals zone widths differ between directions, because faces grow at different rates. Curves are the exact solution for a single step with a fixed rim value (error functions, method of images), in arbitrary units: illustrative, not data.
**c**, For a traverse in any direction, D along the profile is D_a cos²α + D_b cos²β + D_c cos²γ, where α, β and γ are the angles between the profile and the a, b and c axes, taken from the crystal's orientation (e.g. by EBSD). Dashed lines project the profile direction onto the a-c plane, only to show depth. Because a profile fixes D × t, the time scales as width² / D_profile. Read with the D for a different direction, a c-axis profile would give a time up to six times too long.
