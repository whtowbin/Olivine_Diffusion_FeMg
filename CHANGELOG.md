# Changelog

## Unreleased

### Added

- `forster` command (2026-10-12). `forster template DIR` writes `profiles.csv` and `parameters.csv` to fill in, holding one published profile as a worked example (AZ18 WHT01_Ol_63_prof_1, Towbin and Plank 2026), and `COLUMNS.md`. `forster fit PROFILES PARAMETERS --out DIR` fits every run and writes, per run, a figure (`_fit.png`), the model curves, the fitted points with residuals and the kriged profile, plus `summary.csv` (time, 1σ range and every input; it reads back as a parameter table). A failing run is reported and skipped (exit status 1). `--run` picks runs; `--profiles-sheet` and `--parameters-sheet` read Excel.
- Template parameter layout: the Python API's names with units, Fo as a fraction, orientation as angles to the crystal axes or as EBSD Euler angles with the profile direction, fO2 in Pa or relative to a buffer. The round robin and paper layouts are still read. Profile tables in the template layout (`profile`, `distance_um`, `fo`) are detected from their columns.
- `forster.plot_fit(result, ax=None)`, `forster.summary_row(result)`, `forster.fit_tables(result)`, `forster.write_template(dir)`.
- README with installation and the three ways to run (the desktop app follows in the next phase).

- **Choice of diffusivity equation (2026-10-12).** `fit_profile(..., diffusivity=...)`, `RunDefaults(diffusivity=...)` or a `diffusivity` column in a parameter table. The default, `dohmen_chakraborty2007`, is the Fe-Mg equation DIPRA uses (Dohmen and Chakraborty 2007 with erratum; Girona and Costa 2013, Table 1) and is computed by the same code as before, so default results are unchanged (bit-identical; the differential test pins it).
  - Presets (`forster.DIFFUSIVITY_PRESETS`): `dohmen_chakraborty2007`; `mutch2019_tamed` and `mutch2019_global`, the regressions of Mutch et al. (2019, Supplementary Table 1), which give D 0.28 and 0.11 log units above the default at 1200 C; and DIPRA's Ni, Mn and Ca equations (`girona_costa2013_ni`, `_mn`, `_ca`), listed for reference: fits of Fo profiles reject them.
  - Own equations: `forster.ArrheniusDiffusivity` (per-axis log10 D0 and activation energy; fO2, composition, activation-volume and pressure terms; analytic dD/dX_Fo for the DIPRA scheme). It is a frozen dataclass; `shift_activation_energy` and `dataclasses.replace` derive variants. Any object with `name`, `element` and `functions(conditions, orientation)` also works from Python.
  - Command line: `forster template` also writes `diffusivities.csv` holding the presets; add rows there, name them in `parameters.csv`, and pass `forster fit ... --diffusivities FILE`. `forster fit` writes the equations used to `diffusivities.csv` in the output folder, so `summary.csv` refits.
  - Replaces `fit_profile(..., activation_energy_J_mol=...)`, `RunDefaults.activation_energy_J_mol`, `Run.activation_energy_J_mol` and the `activation_energy_J_mol` column of `summary.csv` (now `diffusivity`, the equation's name). For another activation energy, use `DIFFUSIVITY_PRESETS["dohmen_chakraborty2007"].shift_activation_energy(delta)`.
  - Background: `docs/references/diffusivity-literature.md`.
- DIPRA's finite-difference scheme (Girona and Costa 2013, eq. 5) as an alternative to the engine's: `fit_profile(..., scheme="dipra")`, `RunDefaults(scheme="dipra")`, or a `scheme` column in a parameter table. Both schemes solve the same equation and differ only in how the cross term is differenced (DIPRA: forward differences and the analytic dD/dX_Fo; engine: central differences of C and D), so fitting a profile with both is a check on the discretization. Default stays "central".

- **Initial-condition uncertainty: `forster.scan` (2026-10-13).** `scan_initial_conditions` fits a set of candidate initial conditions (for example `step_offsets(initial, range(-6, 7))`, the step at -6..+6 um) and gives the best candidate and time, a profile-likelihood 1-sigma range of time (lower envelope of the candidates' chi-squared) and a marginal one (noise scale integrated out), plus each candidate's probability. One run per candidate; time is never sampled. `progress(i, n)` callback; warns if the best candidate is at the end of the scan. On synthetic profiles with the step 3 um off, coverage of the true time rises from 21-23% (single fit) to 65-74% and the bias from +18% to about +1%. On round robin profile KS20-527_2-transect-1 the scan moves the step from 41 to 46 um (the nominal step is rejected by delta chi2 = 14) and the time from 42 to 24 days.
- **Uncertainties on each step and concentration (2026-10-13).** `forster.scan.Uncertainty(spread, kind)` per parameter (`step1_um`, `step2_um`, `edge_fo`, `core_fo`, `step_fo`): Gaussian (sigma; grid over +-2.5 sigma, prior weight and a ((v - v0)/sigma)^2 penalty in the profile range) or uniform (+- half-width; flat). `candidate_grid` builds the grid (13, 9 or 5 points per parameter by default; invalid nodes dropped and counted; over 2000 candidates refused). In `parameters.csv`: `steps_sd_um` / `steps_range_um` (one value or one per step), `edge_fo_sd` / `_range`, `core_fo_sd` / `_range`, `step_fo_sd` / `_range`, `scan_points`. `forster fit` scans those runs, prints the number of candidates first, writes `<run>_scan.csv`, and adds `scan_*` columns to summary.csv (which refits the same scan); `--max-candidates`. Python: `forster.scan_run`, `scan_summary`, `scan_table`. Scans run on one grid with dt raised until D dt / dx^2 = 0.4 (`scan_grid`; dx unchanged): 2.3-5.8x faster, best fit within 0.2%; coarsening dx instead biased it by up to 12%. With uniform uncertainties containing the truth, a two-parameter scan (step and edge both off) covered it 69% (profile) and 67% (marginal) of the time.
- `forster.uncertainty.posterior_interval`: the Bayesian 1-sigma range with the noise scale integrated out (flat prior on time, 1/s on s). Agrees with the default range to within 5 points of coverage; on real profiles it is about as wide and slightly longer (`docs/references/likelihood-method.md`, section 6).
- **Automatic grid choice (2026-10-13).** Leave `dx_um` and `dt_s` blank and `forster` picks them: dx so the fitted time is within 1% (`final`) or 5% (scans: `scan_dx_um`, `scan_dt_s`, `scan_max_time_days`, all optional), from the diffusion length of a quick coarse fit (error of the time about 0.65 dx / l, measured on six real profiles), and never above a quarter of the narrowest gap between steps; dt at D_max dt / dx^2 = 0.4 for the fastest species; the longest time 3x the coarse fit. Give either part and the other is chosen. A grid you give in full is used as is, but an unstable one (ratio above 0.5) is refused and a coarse, too-fine or slow one gets a warning. summary.csv gains `grid_resolution`, `grid_error_pct` and `grid_stability` and records the chosen grid, so it refits identically. Python: `forster.choose_grid`, `check_grid`, `stable_dt`, `GridRequest`. Scans now set dt exactly at the stable step over all candidates' compositions. Measurements: `docs/references/grid-choice.md`, `docs/plans/2026-10-13-grid-choice/`. The existing parameter tables' grids are stable (ratio 0.007-0.17) and unchanged.
- `FitResult.modelled_days`; `fit_run(..., stop_early=...)` and `fit_profile(..., stop_early=...)`.

### Changed

- **Small-sample correction to the 1-sigma range (2026-10-13), default.** The range is where chi-squared rises by n/(n - p) x t^2(0.8413; n - p) instead of 1 (`forster.uncertainty.interval_threshold`): 1.48 for 6 points, 1.07 for 29, 1.007 for 300. It corrects for the noise being estimated from the same points. Ranges widen by up to 22% for 6 points, 4% for 29, nothing for dense profiles; on synthetic 6-point profiles coverage rises from 49-57% to 60-66% (target 68%). Legacy is unchanged.
- **Early stopping (2026-10-13), default for the correlated method.** The model runs in blocks and stops once it is 2x past the best fit and the residuals are 4x their minimum and rising, extending if the 1-sigma range reaches the end. Fits are identical to full runs on all 35 real profiles; fitting them takes 19 s instead of 129 s. `FitResult.curves` now ends a margin past the fit rather than at `max_time_days`. Legacy always runs the full time.
- **Noise-model warning only for a profile-wide misfit (2026-10-13).** It used to fire whenever the correlation length or amplitude sat at either end of its search grid (25-35% of fits to pure white noise, with no effect on coverage). It now fires when the misfit spans the profile (L at half its length) with an amplitude of at least half the white noise; those cases covered 50-55% against 62-67% otherwise. False alarms: about 1% on pure white noise at 29 points, 8-22% on 6- and 10-point profiles.

- **New default for the uncertainty on the fitted time (2026-10-12).** The best fit and its 1-sigma range now come from the measured points rather than the kriged profile: each model curve is interpolated to the analyses, their errors are modelled as white noise plus a smooth correlated misfit (fitted by maximum likelihood, `FitResult.noise`), and the range is where that chi-squared rises by 1, interpolated between time steps (`forster/uncertainty.py`). Select with `fit_profile(..., uncertainty=...)`, `RunDefaults(uncertainty=...)` or an `uncertainty` column: "correlated" (new default) or "legacy".
  - "legacy" is the rule used from March 2026 for the round robin (`engine.Best_fit_Chi2`: reduced chi-squared of the kriged grid within 1 of its minimum, i.e. chi-squared within N - 1 for N grid points) and reproduces those results exactly. Before March 2026 (paper era) the range was where grid chi-squared reached min + sqrt(2(N-1)) (`engine.Best_fit_Chi2_old`), with time reported as (row + 1) x dt.
  - Why: the old rules counted 150-300 correlated kriged points as independent data and drew the range by rule of thumb (reduced chi-squared, which Andrae et al. 2010 show is undefined for nonlinear models); the kriging variance was also used as a standard deviation, so it had almost no effect. On synthetic profiles with a known time, the legacy range contained it 99.7% of the time when the model is exact and 62% with smooth misfit (target 68%); the new range 71% and 66%.
  - Effect on the 17 round robin profiles: median 1-sigma width (as a share of the best fit) 11% before March 2026, 34% legacy, 24% new (9-36% by profile); best-fit times move by -14% to +8%. Cost: 0.04-0.07 s per fit against 1.9-8.1 s for the model run; faster than the legacy grid chi-squared.
  - `FitResult` gains `uncertainty`, `fit_x_um`, `fit_fo` (the points fitted) and `noise`; `reduced_chi2` now divides by the number of points fitted.
  - Details, coverage tests and the version comparison: `docs/references/fit-uncertainty.md`, `docs/plans/2026-10-12-fit-uncertainty/`.
  - Method, worked example and validation (2026-10-13): `docs/references/likelihood-method.md`, with figures in `docs/references/figures/likelihood/` and the scripts and data in `docs/plans/2026-10-13-likelihood-validation/`. On synthetic profiles with 29 or more points and smooth misfit, coverage is 53-72% (independent errors 20-66%); the correlation length is recovered once it exceeds the point spacing. Initial-condition errors are not in the single-fit range (a 3 um step error: 21-23%); `forster.scan` covers them (65-74%).

### Fixed

- CSV tables are read with exact float parsing (`float_precision="round_trip"`). pandas' default parser returned some values 1 ulp off, so a table written by FORSTER did not refit identically.
- Two step positions without `step_fo` (or three or more steps) are now an error naming the problem; the engine used to fail with an IndexError.

- Cross term of the diffusion equation was doubled (`diffusion_step`, found 2026-10-11). The engine solves dC/dt = D d²C/dx² + (dD/dx)(dC/dx). The cross term was built from two central differences, each spanning two grid spacings, so their product needs dividing by 4Δx²; the code divided by 2Δx². The fix changes `/ 2` to `/ 4`. It affects every Fe-Mg, Mn and Ni model where D varies along the profile, and only those (D depends on Fo). Checked against an independent flux-form solver and against DIPRA's published scheme (Girona and Costa 2013, eq. 5), which converge to the same answer as the fixed engine while the old engine does not (`tests/test_physics.py`; details in `docs/plans/2026-10-11-restructure.md`, "Engine fix").
  - Effect on fitted times: idealised single steps came out 1.3% too short for Fo 0.92 to 0.895 and 8-11% too short for Fo 0.82 to 0.885 and 0.67 to 0.745. The 17 round robin fits move by -28% to +43% (most become 13-43% longer). For Towbin and Plank (2026) the melt-vein medians move by 2-5% (1-3 weeks unchanged) and the exterior contact-overgrowth median by +28% (5.9 to 7.5 days).
